#### 函数：string
语法：string(<数据> [格式 <格式模式>])
返回：字符串。本函数将<数据>转换为字符串，转换时可指定格式。
参数**<数据>**：待转换的原数据，可以是多种数据类型。必要参数；多种数据类型；参数名已省略。
> 将浮点3456.78转为字符串
SQLazy片段: string(3456.78)					//结果是"3456.78"
参数** [格式 <格式模式>]**：转换时用来格式化的模式。非必要参数；类型是字符串；参数名不能省略。
> 将浮点3456.78转为字符串，开头加$符号，中间是千分位，保留2位小数。
SQLazy片段: string(3456.78; 格式 "$#,##0.00") //结果是"$3,456.78"
